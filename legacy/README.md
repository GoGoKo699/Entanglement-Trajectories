# Historical material

The supported implementation is under `src/`, `scripts/`, and `analysis/`.

The original paper-era root scripts are preserved in Git history at commit
`81206df955622c31225f0d4f9c290e35d41ba381`. Before uploading this package, create a branch named `paper-2024-original` from the existing `main` branch. The root-level `.py` files in this release are compatibility notices that prevent the historical scripts from being mistaken for current validated code.

`historical_sources.zip` also preserves the original GPT-5.5 follow-up package and the frozen repository metadata. Historical material is provided for provenance and is not covered by the new-code/content license grant unless explicitly stated inside the archived material.
