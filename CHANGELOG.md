- Reframed the project around the Schmidt-spectrum path and entanglement-trajectory atlas.
- Added exact fixed-largest-eigenvalue envelopes from majorization extremizers.
- Added a canonical metric registry covering separated Rényi sectors and explicit equivalence classes.
- Repaired the GPT-5.5 follow-up computation, including the Marchenko–Pastur CDF defect.
- Quantified metric-robust trajectory morphology, majorization-aware metric competition, and fingerprint limits.
- Added a 58-entry location-specific correction ledger for the 2024 paper.
- Added a public author clarification; a formal journal corrigendum remains a future decision.
- Added five public figures, machine-readable claims/definitions, `CITATION.cff`, CodeMeta, and LLM navigation files.
- Removed obsolete root scripts from the corrected `main` branch while preserving the original code in Git history and the provenance archive.
- Adopted BSD-3-Clause for new code and CC-BY-4.0 for new documentation, figures, metadata, and curated data.
