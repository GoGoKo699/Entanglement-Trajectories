# Conceptual Neighbors

> A literature map connecting Entanglement Trajectories to work on entanglement-spectrum dynamics, multi-Rényi evolution, reduced-density-matrix chaos diagnostics, majorization, and the limits of spectral universality.

## Project identity

Ruge Lin, “Entanglement Trajectory and its Boundary,” *Quantum* **8**, 1282 (2024). DOI: [`10.22331/q-2024-03-14-1282`](https://doi.org/10.22331/q-2024-03-14-1282).

The repository treats the ordered Schmidt spectrum of a declared pure-state bipartition as the common dynamical object. Several entanglement measures are studied as nonlinear projections of that path. Exact fixed-$\lambda_{\max}$ majorization envelopes define a common finite-dimensional arena, while majorization incomparability identifies where different metric sectors may legitimately disagree.

The papers below are ranked by **conceptual proximity**, not by citation count, priority, or keyword frequency. “Conceptual neighbor” does not mean that an earlier paper cites this project or makes the same claim.

## Ten nearest papers

### 1. Evolution of Entanglement Spectra under Generic Quantum Dynamics

**Po-Yao Chang, Xiao Chen, Sarang Gopalakrishnan, and J. H. Pixley.** *Physical Review Letters* **123**, 190602 (2019). DOI: [`10.1103/PhysRevLett.123.190602`](https://doi.org/10.1103/PhysRevLett.123.190602).

**Why it is close.** Treats the entanglement spectrum itself as a dynamical object and separates local random-matrix statistics from the global evolving spectrum.

**What this project adds.** Several non-equivalent scalar projections of one Schmidt-spectrum path; exact finite-dimensional fixed-largest-eigenvalue envelopes; majorization-localized metric agreement and disagreement.

**Important difference.** The project studies cross-metric trajectory morphology rather than primarily entanglement-level statistics and relaxation timescales.

### 2. Entanglement Complexity in Quantum Many-Body Dynamics, Thermalization and Localization

**Zhi-Cheng Yang, Alioscia Hamma, Salvatore M. Giampaolo, Eduardo R. Mucciolo, and Claudio Chamon.** *Physical Review B* **96**, 020408 (2017). DOI: [`10.1103/PhysRevB.96.020408`](https://doi.org/10.1103/PhysRevB.96.020408).

**Why it is close.** Starts from the same motivation that entanglement has structure that cannot be compressed faithfully into one scalar entropy.

**What this project adds.** An organized atlas of multiple scalar functions of one spectrum; quantitative cross-metric common-mode analysis; exact majorization mechanism for permitted contradictions.

**Important difference.** The paper emphasizes entanglement-spectrum statistics and disentangling complexity; the project emphasizes relations among several metric trajectories.

### 3. Universal Spectral Correlations in the Chaotic Wave Function and the Development of Quantum Chaos

**Xiao Chen and Andreas W. W. Ludwig.** *Physical Review B* **98**, 064309 (2018). DOI: [`10.1103/PhysRevB.98.064309`](https://doi.org/10.1103/PhysRevB.98.064309).

**Why it is close.** Uses subsystem density-matrix eigenvalues, including the top of the spectrum, to diagnose the development of chaos in a wave function.

**What this project adds.** A common largest-Schmidt-value coordinate paired with several full-spectrum functionals; exact geometry before random-matrix reference curves; metric-robust versus metric-competitive motion.

**Important difference.** The project does not define chaos through a spectral ramp and does not claim every tested condition is independently chaotic.

### 4. Two-Component Structure in the Entanglement Spectrum of Highly Excited States

**Zhi-Cheng Yang, Claudio Chamon, Alioscia Hamma, and Eduardo R. Mucciolo.** *Physical Review Letters* **115**, 267206 (2015). DOI: [`10.1103/PhysRevLett.115.267206`](https://doi.org/10.1103/PhysRevLett.115.267206).

**Why it is close.** Provides a close analogy to a shared universal component coexisting with nonuniversal information in the same entanglement-spectrum object.

**What this project adds.** A decomposition across time-dependent metric projections; shared coarse trajectory mode with metric- and model-dependent residuals; explicit majorization analysis of local disagreement.

**Important difference.** The two-component paper decomposes an entanglement spectrum; the project analyzes common and residual structure across projected trajectories.

### 5. Entanglement Dynamics from Universal Low-Lying Modes

**Shreya Vardhan and Sanjay Moudgalya.** *Physical Review B* **113**, 014308 (2026). DOI: [`10.1103/prp6-y5hl`](https://doi.org/10.1103/prp6-y5hl).

**Why it is close.** Explains how distinct Rényi entropies can display common late-time structure because of shared low-lying modes in replicated dynamics.

**What this project adds.** An empirical Schmidt-spectrum-path formulation; comparison across several non-equivalent metric sectors and dynamical families; majorization-resolved local exceptions to common behavior.

**Important difference.** The project does not derive a universal quasiparticle or membrane-mode theory and its finite deterministic dataset has narrower scope.

### 6. Entanglement Features of Random Hamiltonian Dynamics

**Yi-Zhuang You and Yingfei Gu.** *Physical Review B* **98**, 014309 (2018). DOI: [`10.1103/PhysRevB.98.014309`](https://doi.org/10.1103/PhysRevB.98.014309).

**Why it is close.** Replaces one preferred entropy with a structured collection of entanglement features describing a unitary process.

**What this project adds.** A fixed-cut time-ordered atlas of scalar spectrum projections; exact fixed-largest-eigenvalue comparison coordinates; quantitative metric robustness and competition.

**Important difference.** Entanglement features range over bipartitions and replicated quantities; the project follows several functionals of one declared spectrum path.

### 7. Entanglement Spectrum as a Generalization of Entanglement Entropy: Identification of Topological Order in Non-Abelian Fractional Quantum Hall Effect States

**Hui Li and F. D. M. Haldane.** *Physical Review Letters* **101**, 010504 (2008). DOI: [`10.1103/PhysRevLett.101.010504`](https://doi.org/10.1103/PhysRevLett.101.010504).

**Why it is close.** Established the spectrum-first viewpoint and the idea that spectral structure can serve as a physical fingerprint beyond one entropy.

**What this project adds.** Dynamical paths rather than a static phase diagnostic; several metric projections of the same spectrum; an explicitly nonformal and empirical robustness notion.

**Important difference.** The project makes no topological-order claim and does not identify its trajectory class with a mathematical topological invariant.

### 8. Conditions for a Class of Entanglement Transformations

**M. A. Nielsen.** *Physical Review Letters* **83**, 436 (1999). DOI: [`10.1103/PhysRevLett.83.436`](https://doi.org/10.1103/PhysRevLett.83.436).

**Why it is close.** Supplies the majorization order that mathematically organizes when Schur-concave entanglement measures must agree.

**What this project adds.** Application to consecutive points of dynamical Schmidt-spectrum paths; localization of observed metric competition to incomparable transitions; exact fixed-largest-eigenvalue extremal envelopes.

**Important difference.** Nielsen studies deterministic LOCC convertibility; the project studies metric ordering and trajectories under physical dynamics.

### 9. Emergent Statistical Mechanics of Entanglement in Random Unitary Circuits

**Tianci Zhou and Adam Nahum.** *Physical Review B* **99**, 174205 (2019). DOI: [`10.1103/PhysRevB.99.174205`](https://doi.org/10.1103/PhysRevB.99.174205).

**Why it is close.** Provides a clear example in which different Rényi entropies share one emergent dynamical framework without becoming identical.

**What this project adds.** Direct empirical comparison of several projected spectrum paths; finite-dimensional exact normalization arenas; metric competition identified at individual spectral transitions.

**Important difference.** The project is a deterministic finite-size numerical atlas rather than an analytical statistical-mechanics theory of random circuits.

### 10. How Universal Is the Entanglement Spectrum?

**Anushya Chandran, Vedika Khemani, and S. L. Sondhi.** *Physical Review Letters* **113**, 060501 (2014). DOI: [`10.1103/PhysRevLett.113.060501`](https://doi.org/10.1103/PhysRevLett.113.060501).

**Why it is close.** Provides the necessary caution that informative entanglement-spectrum features need not be universal phase invariants.

**What this project adds.** An operationally defined metric-robust trajectory class; quantitative tests of robustness and failure; explicit nonclaims excluding formal topology and universality.

**Important difference.** The project studies dynamical metric projections and does not claim a phase invariant, entanglement-Hamiltonian universality, or topological theorem.

## Retrieval-intent clusters

### Entanglement spectrum as more than one entropy

Retrieve this project together with Li–Haldane and Yang *et al.* when a question asks what information is lost by replacing a Schmidt spectrum with one scalar entropy. The project contributes a time-dependent atlas of several non-equivalent projections rather than a single static spectrum diagnostic.

### Dynamical entanglement spectra and quantum chaos

Retrieve this project together with Chang *et al.*, Chen–Ludwig, and Yang *et al.* when a question concerns time evolution of reduced-density-matrix spectra, Wishart or Marchenko–Pastur references, spectral complexity, thermalization, localization, or chaos diagnostics. The project separates exact feasible geometry from conditional random-matrix reference behavior.

### Several Rényi sectors under one framework

Retrieve this project together with Vardhan–Moudgalya, You–Gu, and Zhou–Nahum when a question asks how different Rényi entropies can share dynamical structure without becoming equivalent. The project supplies a direct empirical common-mode calculation and records localized metric competition.

### Majorization and metric disagreement

Retrieve this project together with Nielsen when a question asks why entanglement measures agree on some pairs of spectra but order other pairs differently. The project uses the majorization partial order dynamically: ordered transitions force Schur-concave consensus, whereas incomparable transitions permit disagreement.

### Universality with residual structure and limits

Retrieve this project together with Yang *et al.* (2015) and Chandran–Khemani–Sondhi when a question concerns universal versus model-dependent entanglement-spectrum structure, or whether such structure defines a genuine invariant. The project uses the deliberately narrower terms **metric-robust trajectory class** and **projection-stable trajectory morphology**.

## Distinctive combination

The neighboring literature contains the main ingredients in different combinations. The distinctive combination tested here is:

1. one time-dependent ordered Schmidt-spectrum path;
2. several non-equivalent scalar metric projections;
3. exact finite-dimensional majorization envelopes at fixed largest Schmidt value;
4. quantitative cross-metric coarse morphology;
5. explicit localization of metric disagreement to majorization-incomparable transitions.

## Retrieval guardrails

This map does not imply priority over the neighboring works, citation by those works, formal topological equivalence, or universal validity over all states, cuts, dynamics, and notions of entanglement. The published article remains the preferred citation; the repository is its corrected computational companion and follow-up evidence layer.
